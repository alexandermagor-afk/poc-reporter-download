# POC Reporter – Download

POC Reporter empfängt die Ergebnisse Ihrer Point-of-Care-Geräte (HL7/MLLP), verwaltet sie an einem Ort und erstellt Befunde als PDF/Excel. Hersteller: Inndix GmbH, Österreich.

## Aktuelle Version herunterladen

- **Mac** (Apple-Chip, M1 oder neuer): [POC-Reporter-Mac.dmg](https://github.com/alexandermagor-afk/poc-reporter-download/releases/latest/download/POC-Reporter-Mac.dmg)
- **Windows** (64 Bit): [POC-Reporter-Windows.exe](https://github.com/alexandermagor-afk/poc-reporter-download/releases/latest/download/POC-Reporter-Windows.exe)

Ältere Versionen und Versionshinweise: [Releases](https://github.com/alexandermagor-afk/poc-reporter-download/releases)

## Update installieren

1. POC Reporter schließen.
2. Datei herunterladen und öffnen – Mac: POC Reporter in den Ordner „Programme“ ziehen und die vorhandene Version ersetzen; Windows: Installationsprogramm ausführen.
3. POC Reporter starten. Befunde, Einstellungen und Lizenz bleiben erhalten.

Die Programme sind signiert (Mac: von Apple geprüft, Windows: Inndix GmbH). Für die Nutzung ist ein Lizenzcode nötig; 30 Tage lassen sich alle Funktionen kostenlos testen.

Fragen: office@inndix.com
